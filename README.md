# Flask Projects by Shiva

A collection of small Flask projects and examples, from basics to more advanced usage.

## Projects

- **[simple_flask_app/](simple_flask_app/)** — A minimal Flask app with a couple of routes
  (`/hello/<name>/<age>` and `/admin`), good as a starting point for learning Flask basics.
- **[flask_zillow_sample/](flask_zillow_sample/)** — A sample Flask app that looks up
  property data using the Zillow API via `pyzillow`.
- **[miniproject/](miniproject/)** — A larger Flask app with its own templates
  (login/signin, reports, and data views) and `requirements.txt`.

Each project folder is self-contained; see its own `README.md` (where present) for
project-specific setup notes.
